# homebrew-tap

Homebrew formulae by [@leonardo-bolanos](https://github.com/leonardo-bolanos).

```bash
brew install leonardo-bolanos/tap/ccl
```

## Formulae

| Formula | What it is |
|---|---|
| [`ccl`](Formula/ccl.rb) | [claude-session-switcher](https://github.com/leonardo-bolanos/claude-session-switcher) — lists every Claude Code session and jumps to the iTerm2 window running it |

macOS only: the window jump uses AppleScript against iTerm2.
